# ArmorHub

ArmorHub is a SaaS marketplace platform connecting vehicle owners with professional automotive protection service providers.

## Vision

Build a complete ecosystem for:

- Paint Protection Film (PPF)
- Ceramic Coating
- Window Tint
- Detailing
- Automotive Protection Services

## Architecture

ArmorHub follows:

- API First Architecture
- Domain Driven Design
- Multi Tenant SaaS Architecture

## Applications

```

apps/
├── api              Laravel Backend
├── customer-web     Customer Platform
├── provider-web     Service Provider Dashboard
└── admin            Administration Panel

```

## Packages

```

packages/
├── auth
├── companies
├── vehicles
├── catalog
├── pricing
├── orders
├── payments
├── bookings
├── warranties
└── shared

```

## Development

The project uses:

- Laravel

- Docker
